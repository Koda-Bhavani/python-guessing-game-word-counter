# Python Guessing Game & Word Counter

A simple Python CLI project combining two mini-apps in one main menu.

## Features

### 1. Number Guessing Game (Steps 1-4)
- Random number between 1-100
- 7 attempts to guess
- Hints: Too low / Too high
- Scoring system: 100 points - 10 per extra attempt
- Best score tracking
- Play again option

### 2. Word Counter (Steps 5-7)
- Counts words, characters with/without spaces
- Finds longest word
- Handles empty input

### 3. Main Menu
- Unified menu to choose game
- Loop until exit
